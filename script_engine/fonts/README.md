# Fuentes bundleadas

- **Anton-Regular.ttf** — familia *Anton*, licencia **SIL Open Font License 1.1 (OFL)**, libre
  para uso/redistribución/embedding. Fuente: Google Fonts (`ofl/anton`).
  Se bundlea acá para que el overlay de miniaturas (`m09_packaging.py`) NO dependa de fuentes
  del sistema Windows. Es la misma familia que usan los subtítulos (`fase2b.py`, estilo Anton).
- **PlayfairDisplaySC-Bold.ttf** — familia *Playfair Display SC* (Bold), licencia **SIL Open Font
  License 1.1 (OFL)** (`OFL_PlayfairDisplaySC.txt`). Fuente: Google Fonts (`ofl/playfairdisplaysc`).
  Candidata (F1b §2.5) a tipografía de callouts/archivo distinta del Anton de los subtítulos.
